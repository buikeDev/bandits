We are building BANDIT, an ecommerce and fulfilment platform.

The primary business is wristband sales:

- Tyvek wristbands
- Vinyl/plastic wristbands
- Rubber/silicone wristbands
- Fabric wristbands
- VIP wristbands
- Hospital/identification wristbands
- Plain and custom printed variants

The platform also supports:

- custom wristband printing
- bulk orders
- third-party products from fulfilment clients
- fulfilment services for businesses

Frontend:
Next.js + TypeScript + Tailwind.

Backend:
Node.js + Express + TypeScript.

Database:
PostgreSQL + Prisma + Neon.

Use a modular monolith architecture.

Do not start building random pages yet.

First inspect the repository and establish:

1. workspace structure
2. frontend architecture
3. backend architecture
4. shared packages
5. environment variable examples
6. linting and formatting
7. base documentation

Do not implement authentication, products, checkout or database models until this foundation is complete.
